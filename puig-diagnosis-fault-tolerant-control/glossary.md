# Glossary — Puig & Simani, Diagnosis and Fault-tolerant Control (2 vols, ISTE 2021)

## IFAC SAFEPROCESS terminology (Vol 1 Introduction, the book's official vocabulary)
- **Fault** — unpermitted deviation of at least one characteristic property/parameter of the system from the acceptable, usual or standard condition.
- **Failure** — permanent interruption of a system's ability to perform a required function under specified operating conditions.
- **Malfunction** — intermittent irregularity in fulfillment of a desired function.
- **Error** — deviation between measured/computed value of an output variable and its true/theoretically correct value.
- **Disturbance** — unknown and uncontrolled input acting on a system.
- **Residual** — fault indicator based on deviation between measurements and model-equation-based computations.
- **Symptom** — change of an observable quantity from normal behavior.
- **Qualitative model** — static/dynamic relationships describing behavior in causal or IF-THEN terms.
- **Diagnostic model** — relationships linking symptoms (inputs) to faults (outputs).
- **Analytical redundancy** — determining a variable by more than one way, one being a mathematical process model in analytical form (software, no extra hardware).
- **Reliability / Safety / Availability** — perform under stated conditions over time / operate without danger / probability of satisfactory operation at any time.
- **Abrupt fault** — step-shaped (bias). **Incipient fault** — ramp-shaped (drift). **Intermittent fault** — impulse combination.
- **Additive fault** — enters variables by summation. **Multiplicative fault** — enters as parameter products.

## Residual generation & evaluation
- **EE / OE** — equation error (prediction) vs output error (simulation) identification residuals; OE needs numerical optimization.
- **UIO** — unknown-input observer: residual decoupled from states, known inputs, unknown inputs; sensitive only to faults.
- **Fault detection filter** — Luenberger observer with gain shaping residuals into fault-specific directions (directional residuals; isolation = nearest signature).
- **Parity equations / parity space** — consistency check of measurements via projection onto parity space (Potter–Suman static, Gertler dynamic).
- **Innovation** — KF prediction error; whiteness/mean changes signal faults.
- **Adaptive threshold** — passive robustness: threshold ε(t) generated by a linear system driven by u(t), tracks operating point.
- **Active robustness** — model modeling errors as approximate disturbances and decouple them at design stage.
- **H−/H∞ index** — maximize fault→residual gain (H−) while minimizing disturbance→residual gain (H∞).
- **Fault signature (matrix)** — pattern of residuals/estimators responding to each fault; basis of isolation.

## Structural analysis (Vol 1 Ch2)
- **Structure graph** — bipartite graph of equations E and variables X.
- **Matching / redundant relation (RR)** — maximal matching; unmatched equations yield redundant relations.
- **ARR** — analytical redundant relation: RR with unknowns eliminated = residual generator.
- **Dulmage–Mendelsohn (DM) decomposition** — splits model into underdetermined (G−), exactly determined (G0), structurally overdetermined (G+ = M+) parts.
- **Structural detectability** — fault detectable iff its fault equation lies in M+.
- **Structural isolability** — fi isolable from fj iff efj ∈ (M \ {efi})+; **fault isolability matrix** collects all pairs.
- **PSO / MSO set** — proper structurally overdetermined (M = M+); minimal PSO (redundancy degree 1) = candidate residual generator source.
- **TES / test support** — test equation support: PSO set whose fault set can't be enlarged by another PSO.
- **MEC / MEM / PC** — minimal evaluable chain / minimal evaluable model / **possible conflict** (Vol 1 Ch6): executable monitor of a subsystem; PCs ≡ minimal conflicts ≡ minimal ARRs ≡ MSO sets.

## Set-based & stochastic (Vol 1 Ch3–4)
- **Zonotope** 〈c,H〉 — center + generator matrix; unknown-but-bounded set closed under linear maps and Minkowski sum.
- **Set-membership estimation** — predict state set, intersect with output-consistent set; P-radius contraction LMIs.
- **Zonotopic Kalman gain** — minimizes Frobenius radius of generator matrix (Combastel).
- **Stochastic diagnosis** — inverse problem: reconstruct fault variable φ from data y through likelihood π(y|φ); model-driven (MCMC, particle filters, Bayesian inversion), data-driven (learned pseudo-inverse classifier), hybrid (surrogate/gray-box).

## Data-driven & AI (Vol 1 Ch5–6, Vol 2 Ch1, Ch3)
- **EIV / Frisch scheme** — errors-in-variables identification when both u and y are noisy; recovers noiseless model + noise variances from covariance null-space structure.
- **TS (Takagi–Sugeno) model** — fuzzy rules with affine/homogeneous consequents; weighted average of local linear models; multiple-model structure.
- **PWA / hybrid model** — piecewise-affine submodels + switching; universal approximation in Sobolev norm.
- **NF (neuro-fuzzy)** — NN learning + fuzzy interpretability; TSK + NN learning algorithms; hierarchical NF for dimensionality.
- **CBD (consistency-based diagnosis, Reiter)** — (SD, COMPS, OBS); AB(c) predicate; **conflict** = set of components with at least one faulty; **minimal diagnoses = minimal hitting sets of minimal conflicts**.
- **KBS / heuristic classification** — production rules + inference engine (MYCIN); abstraction→matching→refinement.

## FTC (Vol 2)
- **PFTC / AFTC** — passive (robust design tolerating a fault class without diagnosis) vs active (diagnose magnitude, reconfigure).
- **LPV / quasi-LPV polytopic model** — vertex systems blended by convex scheduling functions ρi; quasi-LPV when ρ depends on x̂.
- **Descriptor system (E,A,C)** — DAE model; R-observability and impulse-observability per vertex.
- **RPO** — robust polytopic observer jointly estimating state and fault (Vol 2 Ch2).
- **NLGA** — nonlinear geometric approach (De Persis–Isidori): maximal (C,A)-invariant distribution in ker(dh); coordinate change isolating one fault from disturbances.
- **PDC** — parallel distributed compensation: TS-fuzzy state feedback K(hk) blended by membership weights.
- **Block P-matrix test** — feasibility check that all convex combinations of Bi stay full rank (Vol 2 Ch3).
- **Robust invariant set** — set kept invariant under disturbance via feedback; ellipsoidal bounding as inner approximation (Gilbert–Tan exact set).
- **Error model** — NN model of the nominal model's own prediction error; composite nominal+error model for robust MPC.
- **Virtual sensor** — static or dynamic block (gain M) replacing a faulty sensor channel so nominal controller/observer stay untouched.
- **Virtual actuator** — block (gain N) redistributing/reconfiguring a faulty actuator channel.
- **Extended separation principle** — with virtual blocks, stability of nominal (A−BK, A−LC) plus stable virtual dynamics (eig M, eig N) suffices for fault-tolerated closed loop.
- **Digital twin** — high-fidelity simulation used to validate FDI/FTC before plant deployment.
