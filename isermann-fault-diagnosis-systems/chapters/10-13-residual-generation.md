## Isermann Ch10 — Parity-Equation Residual Generation

### 10.1 Parity equations with transfer functions
- Setting: linear process; model known with fixed params. Process Gp(s)=Bp(s)/Ap(s), model GM(s)=BM(s)/AM(s) [reconstructed]; model error ΔGM = Gp − GM.
- Two residual schemes (Fig. 10.1): (a) output-error, (b) polynomial/equation-error.
- SISO output error: r'(s) = y(s) − GM(s)u(s) [reconstructed] — zero iff ideal match + no additive faults + no noise; otherwise driven by ΔGM, noise, excitation u.
- SISO equation error: r(s) = AM(s)y(s) − BM(s)u(s) [reconstructed] ("multiply through by AM"). Additive input faults fu get filtered by BM(s); output faults fy by AM(s) — i.e. higher-order derivatives of faults appear.
- Eqs (10.4)/(10.5) = the parity equations; r' and r = PRIMARY residuals [10.8].
- MIMO: computational form r = y − GM(s)u (transfer-function matrix). Substituting assumed fault structure gives INTERNAL form (a.k.a. unknown-input-effect form / evaluation form) [10.8][10.4] — explicit fault→residual transfers. If model=process exactly, internal form reduces to faults+noise only [formulas not decoded; standard form r = fy + Gp·fu + ny + Gp·nu].
- Polynomial residual MIMO: written with polynomial matrix description A_M(s)∘y − B_M(s)∘u; same computational/internal-form split.
- Number of residuals = number of measured outputs.
- Key relation between the two primary residuals: r(s) = AM(s)·r'(s) [reconstructed from "related by" + text] — the polynomial residual differentiates signals (realizability problems, amplifies high-frequency noise).
- Isolation hook: if only a single input or output fault acts, residual vector components deviate differently (some stay zero) → additive-fault separation/isolation possible (developed in 10.3).
- Example 10.1 (simulated 1st-order process, [10.19]): G(s)=K/(Ts+1) [reconstructed], operating point (Up, Yp). Faults: ΔK and/or ΔT, each stepwise or ramp (mimics abrupt vs drifting faults); input either held at Up or steps Up→U1 at fault onset. Parity eqs: output-error one (model coeffs indexed M) and equation-error one; schemes = Fig. 10.1.
- Process param faults (b): step ΔK w/ constant input → residual step, steady-state offset ∝ ΔK·Up [reconstructed]; adding input step at fault instant adds transient terms. Step ΔT w/ constant input → residual has only transient; text: "during steady-state operation, the parity equations are insensitive to faults in [T]" [OCR: sentence truncated, "insensitive to faults in if..."]. ΔT detectability even in dynamic operation is hard: input step excites residual only dynamically (transient-only response) [reconstructed]. Fig. 10.2: residual time histories for step/drift ΔK, ΔT × (no input change | step input).
- Noise influence (d): noise attack points identical to additive-fault points; PSDs S(ω) at input/output. Output-error scheme: input noise nu enters LOW-PASS filtered (dc ω=0 component attenuated by gain K [OCR "«2 = 0"]; equation-error: input noise attenuated by frequency-independent gain K (all components same). Output noise ny: added directly to r'(t) (no filtering, gain 1); for equation error r(t) the output noise is HIGH-PASS filtered, gain > 1 at all frequencies; text says "high frequencies are attenuated with a large gain" [OCR — contradicts summary, which says r amplifies output HF noise by (1 + ω²T²) — amplification is correct].
- Summary (e), from [10.19]: (i) threshold design: no difference r' vs r for faults in K or simultaneous K&T → pick residual by other criteria (noise). (ii) For faults in T: with stepwise fault + stepwise excitation, r(t) reacts stronger than r'(t) → prefer EQUATION error provided no output noise. (iii) Additive input/output faults: both residuals reach same t→∞ value; r' slower (lagged by process T) → prefer r if speed matters. (iv) HF noise at INPUT: prefer r' (LP behavior filters it); r amplifies low-freq noise equally for both, but HF input noise favors r'. (v) HF noise at OUTPUT: prefer r' (components unchanged); NEVER use r (amplifies by 1+ω²T²).
- Table 10.1 (OCR heavily garbled, structure salvageable): rows = fault/noise type (ΔK, ΔT step/drift, fu, fy, nu, ny); columns = duration of reaction (long/short/none) for r' and r, ease of threshold design (+ easy / − difficult), reaction due to noise (LP / HP / G = attenuation by gain). Qualitative entries match (i)-(v) above.
### 10.2 Parity equations with state-space models
#### 10.2.1 Continuous-time parity approach (orig. [10.5], also [10.7][10.12]; Fig. 10.4)
- Model: ẋ = Ax + Bu + Bv·v + f ; y = Cx + Du + n [reconstructed standard form; formulas not decoded]. v = unmeasurable inputs/disturbances, n = noise, f = additive faults composed of input faults fu and output faults [formulas not decoded].
- Trick: generate REDUNDANCY at the SAME time instant t — take y and its derivatives up to order q < n, stack into Y(t); stack input derivatives into U(t):
  Y = T·x(t) + QU·U(t) + QV·V(t) (+ fault/noise vectors) [reconstructed from text].
  T = [C; CA; CA²; …; CA^q] observability-type matrix; QU = lower-triangular Markov-parameter matrix (D, CB, CAB, …) [reconstructed].
- Matrix orders for order-n system, p inputs, pV disturbances, r outputs: Y = (q+1)r×1; U = (q+1)p×1; T = (q+1)r×n; QU = (q+1)r×(q+1)p; QV = (q+1)r×(q+1)pV.
- PARITY VECTOR w^T: multiply equation by w^T and impose w^T·T = 0 (and w^T·QV = 0 to kill unknown disturbance v) → unknown state x drops out [reconstructed conditions; text: "part of the elements of w^T is determined according to order of T and QV, remaining elements used to design different parity equations"].
- Computational form: r = w^T[Y − QU·U]. Internal form: r = w^T[fault terms F(t) + noise terms N(t)] — explicit fault→residual map. If condition satisfied: residual independent of unknown v(t) and states x(t).
- Several w vectors → matrix W; residual vector r = W^T(...); ORDER of W = number of parity equations. Max independent count = dim left-nullspace of T = (q+1)r − n [reconstructed standard result].
- s-domain transform of residual resembles equation-error parity residual (10.5).
- PRACTICAL DRAWBACK: needs derivatives up to q of measured u,y (via state-variable filters [10.17], ch.23.2); uses single-time-instant info → noisy results expected → DISCRETE-TIME version preferred (next section).
#### 10.2.2 Discrete-time parity approach (Fig. 10.5; [10.5][10.7][10.12])
- Discrete process: x(k+1) = Ax(k) + Bu(k) + f(k) + Bv·v(k); y(k) = Cx(k) + Du(k) + n(k) [reconstructed; formulas not decoded]. v(k) unmeasurable disturbance, n(k) noise, f(k) additive faults (composed of input fu and output faults).
- Derivation: iterate the state equation forward — y(k), y(k+1)=CAx(k)+CBu(k)+Du(k+1), …, i-th shifted sample (i ≤ q). Stack over a time window of length q+1:
  Y(k) = [y(k−q) … y(k)]ᵀ, U(k) = [u(k−q) … u(k)]ᵀ (shifted-by-q version, eq. 10.38/10.39),
  Y = T·x(k−q) + Q·U [T = [CA^q; …; CA; C] stacked observability; Q = lower-triangular Markov matrix D, CB, CAB…] [reconstructed].
- (10.38) ties (q+1) samples of u,y to the initial state x(k−q) → TEMPORAL redundancy [10.23] (contrast: continuous approach = redundancy at one instant).
- Parity vector: wᵀ with condition wᵀT = 0 (10.42) → unknown state eliminated; computational form r = wᵀ[Y − Q·U].
- Dimensions: wᵀ = 1×(q+1)r (r = number of outputs); T = n×(q+1)r; condition determines n elements of wᵀ; remaining (q+1)r − n elements FREE for design.
- Multiple residuals: matrix W with WᵀT = 0 (10.44); r = Wᵀ[Y − Q·U] (10.45). Free elements of W shape residual properties (e.g. structured residuals, §10.3; examples [10.16][10.14]).
- Window length q+1 free; usually q = n is a proper choice [10.5].
- Unknown inputs v(k): additionally require WᵀQV = 0 (10.46), QV like Q but built from Bv instead of B [10.14].
- Internal form after inserting faults/noise (10.47): r = Wᵀ[Qf·F + Qn·N] (Qf, Qn like Q) — residual depends ONLY on additive faults + noise.
- Practical: residuals have relatively large variance (noise + process-model deviation) → must LOW-PASS FILTER them.
- Tradeoff vs transfer-function version: state-space gives MORE freedom choosing W, but uses LESS signal time-history → more noise-sensitive, more computation, less straightforward.
### 10.3 Properties of residuals
- Ideal: residuals influenced only by faults to detect. Reality: modelling errors, unknown inputs, stationary/nonstationary output disturbances keep residuals moving → wide thresholds → small faults undetectable. Five remedies:
  - enhanced residuals (for particular faults);
  - low-pass filtering to remove HF noise while preserving slow (low-frequency) fault signatures;
  - maximizing fault sensitivity of residuals;
  - robustness against modelling errors;
  - adaptive thresholds, e.g. depending on input excitation.
- Common goal: sensitive to faults, robust to disturbing effects.
#### 10.3.1 Generation of enhanced residuals ([10.8])
- Primary residuals (output/polynomial models) do not necessarily allow fault separation; state-space design leaves freedom in W → exploit it. Two approaches: STRUCTURED and DIRECTIONAL residuals (Fig. 10.6a/b).
- (a) Structured: each fault influences SOME residuals and leaves others unaffected → residual patterns = FAULT SIGNATURES; residual vector lives in certain subspaces of residual space; residual vector at least independent/decoupled from one fault each.
- (b) Directional: each fault maps to a fixed vector DIRECTION in residual space; length ∝ fault size; direction maintained even during dynamic transients.
- Limit checking: thresholds r_th (same for ±); binary outputs r* ∈ {0,1}, r*=1 = threshold exceeded.
- Isolation quality (Table 10.2 legend): STRONGLY isolating — a single residual's decision error never yields a wrong fault; WEAKLY isolating — one residual decision error can isolate a wrong fault; NOT isolating — patterns indistinguishable. More special cases in [10.8].
- Table 10.3 (no sign, 2 residuals, patterns 0/1 per fault): no-fault (0,0); f1 (1,0); f2 (0,1); f3 (1,1) → 3 faults weakly isolable with 2 residuals; general count = 2^n − 1 faults for n residuals [formula not decoded; reconstructed standard].
- Using SIGN (separate +/− thresholds ri+, ri−) and even SIZE expands pattern set: max patterns for 2 residuals = 7 [text], general formula = 3^n − 1 [reconstructed; book confirms 26 for n=3; Table 10.4 lists 7 faults for n=2].
- With sign: 3 residuals → 7 distinguishable faults binary vs 26 with sign (matches 2³−1 and 3³−1 [reconstructed formula]) → considering residual SIGN increases isolable fault count considerably.
- Going further — quantize SIZE of deflection (residual marked by magnitude levels, formula not decoded): 2 residuals → theoretically 24 combinations (Table 10.5; = 5²−1 if levels {−−,−,0,+,++} [reconstructed guess]); general formula not decoded. In practice not all combos appear; sign+size evaluation improves isolation, finer diagnosis, and multiple-fault detection.
#### 10.3.2 Generation of structured residuals
- Goal: good isolating signature patterns; residual at least decoupled from the faults to be detected. Directly possible for ADDITIVE faults (input fu, output faults), so mainly that case considered.
- Method: take polynomial/equation error of MIMO process (p inputs, r outputs, eq. 10.4), multiply by residual-generating matrix W(s): r* = W(s)∘r. Choose W so that each component of r* becomes independent of one measurement each (one y_i and/or u_j): rows of W chosen to null the corresponding polynomial-matrix columns; conditions (10.52) style. Result: DYNAMIC parity polynomials wi(s) giving r*(s) the required independence from specific input/output signals.
- Example 10.2: single-input two-output process — two parallel 1st-order lags G1=K1/(T1s+1), G2=K2/(T2s+1) [reconstructed], Fig. 10.7. Physical case: u = steering angle δ of vehicle; outputs = yaw rate ω and lateral acceleration [OCR garble]; goal = detect OFFSET faults in all 3 sensors.
  - Rearranged process eqs (T1s+1)y1 = K1u; (T2s+1)y2 = K2u; vector form stacks [y1 y2 u] against polynomial matrix [formulas not decoded].
  - To make residuals independent of 3 signals (y1, y2, u): multiply by residual-generating matrix W(s); independence reached by row conditions [not decoded]; three residuals result.
  - SHORTCUT noted in text: the same residuals follow directly from the two channel transfer functions by cross-multiplying, moving all terms to one side, and replacing the 0 by rk. Nice construction rule.
- Table 10.6 fault signatures (OCR garbled; qualitative): sensor offset faults fy1, fy2, fu → distinct signatures with one/two active residuals → residuals STRONGLY ISOLATING for the three offset faults, even when their signs differ.
- Gain changes ΔK1, ΔK2 vs offset faults: only distinguishable from fy1/fy2 if their deviations have the same sign; sign usually unknown → practically undistinguishable.
- Time-constant changes: residuals deflect only while input u(t) changes, and only passing/small deflections → practically not detectable. Results valid for changing and constant inputs alike.
- Residuals contain DERIVATIVES of output signals → HF noise problem → apply low-pass filters (damps residual responses too).
- Applying the same procedure to the OUTPUT-error form (10.6): an alternative residual set results [formulas not decoded] that needs NO extra low-pass filters — no realizability problems (proper transfer).
- Bottom line: additive faults on all 3 measurements isolated by structured parity equations.
- Example 10.3: Structured residuals for a DC motor (brush-commutated; modeling in Ch.20; Fig. 10.8 signal-flow diagram).
  - Numerical params (OCR garbled, read with care): Rg = 1.532 [Ω]; L_A = 6.8·10⁻³ [Ω·s = mH] [OCR "6.8 1073Qs"]; c(e.m.f. const, printed as W) = 0.34 [Vs]; M_F(friction) = 0.37·10⁻³ [Nms] [OCR "0.37103"]; J = 1.9·10⁻² [kg·m²] [OCR "1.9 102k gm?"].
  - Two linear ODEs: electrical armature circuit + mechanical part [formulas not decoded; standard: UA = R·iA + L·diA/dt + c·ω; J·dω/dt = c·iA − Mp·ω − ML].
  - Vector notation of the two Laplace equations; multiply by residual generation matrix; independence demanded w.r.t. measured signals (UA, iA, ω) AND unknown load torque ML → matrix determined [not decoded]; residuals given in TIME domain.
  - Derivative burden: residuals need 1st derivatives of UA, iA, ω and 2nd derivatives of iA and ω [OCR "IA(t) and w(t)"] → practically only solvable via low-pass filtering of measurements and especially STATE-VARIABLE FILTERS [10.14], ch.23.2.
  - Drawback: load torque ML must be KNOWN for all residuals except one (r4) [OCR "rq"].
  - Shortcut again: solve state variables ω(s), iA(s) from the signal-flow diagram as functions of measurables + inputs (UA, ML); each equation then reads (expression)=0; replace 0 by ri(s) → residual. So residuals = special transfer functions of the process in which each ONE measurement is eliminated.

  - Conclusion of example: additive sensor faults detectable+isolable PROVIDED process parameters stay constant; these parity equations NOT suitable for detecting/isolating parameter faults. (Real DC-motor application: Ch.20.)
  - Multiple faults: two simultaneous additive sensor faults, sign-only evaluation, Table 10.8: single-fault effects on residuals partially cancel / partially add, but ALL combined signatures differ and are mostly still strongly isolating → double sensor faults detectable and isolable using these signatures.
#### 10.3.3 Sensitivity of parity equations ([10.15], also [10.9])
- One residual written as r(t) = Θᵀ(p)·w(t): Θᵀ(p) contains process parameters (functions of physical parameters p); w(t) stacks measured input/output signals AND their derivatives [reconstructed from text; formulas not decoded].
- Small ADDITIVE fault Δw(t): r = Θᵀ(p)·Δw(t) (fault-free case r=0). With constant parameters: sensitivity coefficient = Θᵀ(p); residual proportional to additive fault and INDEPENDENT of input excitation U(t).
- PARAMETRIC fault Δp(t): model keeps fixed params Θᵀ(p0); process follows new differential equation → signal change Δw(p0,Δp) [not decoded]. Residual = [Θᵀ(p)−Θᵀ(p0)]·w0 + Θᵀ(p0)·Δw [reconstructed split]. Sensitivity ∝ process parameter-sensitivity of model × measured signals w(t).
- KEY RESULT: parametric-fault sensitivity DEPENDS ON INPUT EXCITATION; for U(t)=0 no parametric fault can be detected. (Consistent with 10.1: time-constant faults need dynamic excitation.)
### 10.4 Parity equations for nonlinear processes
#### 10.4.1 Special nonlinear processes
- No general recipe (too many nonlinear model classes), BUT if the nonlinear model is LINEAR-IN-PARAMETERS polynomial form [structure not decoded], output residuals follow directly.
- Holds for discrete-time polynomial models: HAMMERSTEIN and parametric VOLTERRA (Sec. 9.3.2); Hammerstein output residual given [not decoded]; even EQUATION-ERROR residuals possible for these polynomial models [not decoded].
- BILINEAR state model (Sec. 5.2.4, u multiplies states x(k)): [10.14] generates parity equations (continuous time) by decoupling from the bilinear term ui·xi, analogous to §10.2.1 parity-vector design.
- Artificial neural nets (Sec. 9.3.3): directly usable for output residuals (case studies [10.18]).
#### 10.4.2 Parity equations for nonlinear local-linear models (TS fuzzy; after [10.2], model type [10.25]; follows Peter Ballé [10.3])
- Approach: Takagi–Sugeno fuzzy model of the NOMINAL process, built from heuristic knowledge and/or identification. Transparent inner structure → generate symptoms indicating occurrence AND LOCATION of sensor faults; continuous fault detection for nonlinear processes across ALL operating ranges. Model run both in parallel (multi-step prediction) and series-parallel (one-step prediction) → different fault sensitivities; final scheme COMBINES both. Demo: industrial-scale heat-exchanger pilot plant [10.2][10.18].
- (a) Fuzzy-neuro model: MISO, discrete time (z-domain). y = fyz(u…) nonlinear+dynamic → TS fuzzy model, M rules with LINEAR DYNAMIC consequents: params b0i…bni (linear regression of rule i), Ai(z), Bij(z) = MA filters in z. Input split: consequent inputs uc ⊆ u set local linear dynamic behavior; premise inputs up ⊆ u carry the variables that drive the nonlinear (operating-point-dependent) characteristic (= z of Sec. 9.3.3c). Different premise/consequent input spaces often useful/necessary.
- Fuzzy sets Pi over up; normalized Gaussian membership; product t-norm; output = Σ φi·(rule consequent), φi = normalized Gaussian with center ci, std dev σi → nonlinear INTERPOLATION between rule consequents. Fig. 10.9 numerical example: static, two inputs, 3 rules / 3 local linear models. Advantage: interpretability — each consequent describes the process at its premise's operating point.
- Construction: LOLIMOT (LOcal LInear MOdel Tree) [10.20]: tree-like outer loop fixes ci, σi; then weighted linear least squares for consequent parameters. Alternatives [10.24].
- DYNAMIC LINEARIZATION [10.6]: model rewrite where every parameter of polynomials Ai, Bi is a nonlinear interpolation of consequent parameters → linear model with OPERATING-POINT-VARYING parameters (Fig. 10.10). Beats Taylor linearization of TS models, which suffers "bubble" effects from rule premises [10.1]. Also viewable as neural RBF-weighted local linear model (LOLIMOT) [10.21].
- (b) Sensor-fault FD scheme: nonlinear MIMO system, r outputs, m inputs, order n; for each output y_i a local linear model identified (depends on all inputs/outputs); coefficients aij(k), bij(z) move with up (as in 10.74). Raw residual vector r(z) depends on ALL signals → decouple by multiplying with residual generator w(z): vector of length r whose elements wij(z) are MA filters; impose wᵀ(z)·(column of system polynomial matrix for y_i or u_i) = 0 → residual decoupled from that output/input.
  - A suitable w always exists, BUT sometimes generators for different signals turn out EQUAL → no isolation possible between those faults.
  - Row vectors wᵀ stack into residual-generator matrix W(z). Because Ai, Bi and W depend on premise inputs up, the residual generator must be RECOMPUTED ONLINE every sample interval. Fig. 10.11.
- Parallel vs series-parallel (Fig. 10.11): series-parallel = equation-error model, predicts with previous PROCESS outputs y(k−d); parallel = output-error model, feeds back previous MODEL outputs. Residual behavior differs [10.13]: series-parallel uses measured (noisy) outputs → smaller SNR, often needs low-pass filtering; parallel models drift with model uncertainty (auto-regressive part), performance worse, can even go unstable [10.22].
  - Parallel-model parity eqs: + even small faults give larger residual deflections; + relatively high SNR; + no filter needed; − hard to build, worse performance; − likely to drift (imprecise modeling); − parity equations have auto-regressive part.
  - Series-parallel parity eqs: + high peaks on sudden changes; + very fast response but small deflection; + no auto-regressive part; + no drift → smaller output error; − small SNR; − need low-pass filtering.
- Combination strategy: compute sensitivities, select the MOST SENSITIVE residuals. Applications: heat-exchanger sensor faults [10.2][10.18]; pump–pipe system with neuro-fuzzy local-linear/operating-point-dependent params [10.26][10.27].
### 10.5 Parameter estimation with parity equations
- From §10.3.3: small parameter change Δpj gives residual r = si·Δpj [reconstructed], with si = scalar RESIDUAL SENSITIVITY w.r.t. pj, computed from the process model (10.82/10.83 not decoded).
- Invert it to ESTIMATE the fault: r(k) = si(k)Δpj + e(k) (e = equation error), samples k = 0,1,2,… (sampling time Tμ [OCR "A = 1/Ty" reversed; reading A=Tμ?]). Stack N samples into vectors → nonrecursive LEAST-SQUARES estimate of Δpj (§9.2.1): Δp̂j = (sᵀs)⁻¹sᵀr [reconstructed] — a correlation of residual sensitivity si with residual r.
- Recursive version with exponential forgetting follows (9.98)–(9.100) [formulas not decoded].
- Recursive LS with exponential forgetting, λ < 1.0, start value P(0) = a·I with a = 1000 [OCR "a@" garbled; reconstructed] per (9.98)–(9.100).
- Rule: ONE residual ri(k) → ONE estimated parameter deviation Δpi(k). Use to ADAPT one parameter of the parity-equation FD scheme when that parameter is known to drift from NORMAL operating conditions. If FAULTS are expected to change parameters, prefer direct parameter estimation of all process parameters instead.

## Isermann Ch11-12 — Observer Residual Generation, Closed-Loop Fault Tolerance

### Ch11 State observers for residual generation (11.1, src 5867-6016)
- Setup: LTI multivariable process, state-space x' = Ax + Bu, y = Cx + Du, p inputs u / r outputs y; observer reconstructs unmeasurable x̂ from measured u,y (Fig 11.1): x̂' = Ax̂ + Bu + H(y − ŷ), ŷ = Cx̂ + Du. Output error e = y − ŷ fed through observer matrix H. Requires observability.
- State error ε = x − x̂ obeys ε' = (A − HC)ε [reconstructed standard form] → vanishes asymptotically for any ε(0) if observer stable, designed by pole placement of H. Observer poles: left half-plane, faster & better damped than process poles, but not too fast — large H amplifies output noise n; compromise.
- Additive faults (11.1.1, Fig 11.2): process gets input disturbances v(t) [m×1], output disturbances n(t), additive input faults f_a(t) and output faults f_m(t) via fault-entry matrices L, M. After initial-error transients die, ε and e = r(t) depend on v, n, f_a, f_m — residual is 0 with none, nonzero with any. Key property: residuals do NOT depend on process input u(t).
- ε usable as residual when state/input faults (leak detection) are of interest; generally output error e = r used as residual.
- Laplace view: observer residuals = internal form of parity equations (cf. Ch10 eq 10.8): f_a acts through observer dynamics [sI − (A − HC)]⁻¹, f_m acts directly on e additionally. Step faults f_a0/f_m0 → constant residual offset (static deviation) in both e and ε.
- vs parity equations (eq 10.7): observer dynamics [sI − (A − HC)]⁻¹ plays the role process transfer Gp(s) played there, between additive input faults and output error.
- Multiplicative faults (11.1.2): parameter errors ΔA, ΔB, ΔC → state/output errors depend on parameter changes MULTIPLIED by u(t) and x(t) → behavior not a simple input-output transfer, analysis harder than additive.
- Isolation (11.1.3): primary residual e needs enhancement for single-fault determination (as parity Sec 10.3) → fault-detection filters or dedicated observers, mostly bank of observers; requires multiple process outputs.
- Fault-detection filter / fault-sensitive observers ([11.3],[11.16]): exploit design freedom in H to structure residuals: each fault f_ai has a fault influence vector l_i; design for m linearly independent vectors l_i so residual directions identify the fault.
- Fault-detection filter design (cont., eqs 11.22-11.30): assume fully measurable states (C invertible → x recovered from y) to derive residual dynamics; introduce diagonal matrix Λ with fast, equal eigenvalues to decouple residuals from each other; H then follows from a matching equation [formulas not decoded]; if states not measurable, model transformations needed ([11.3],[11.16]; example [11.12]; further procedures [11.21],[11.30]).
- Bank of observers (dedicated observers) for isolation: r observers, each driven by a subset of I/O; the observer missing the faulty I/O stays quiet → disagreement pattern isolates fault. Scheme (a) Fig 11.3a [11.7]: all inputs u, only output k → sensor fault f_mk affects ONLY residual r_k, all other r_i = 0 → pattern isolates additive sensor fault. Scheme (b) Fig 11.3b [11.31],[11.26]: all outputs y, only input u_i → detects input/actuator faults f_ai.
- Generalized observer scheme [11.9]: each observer uses all inputs and outputs EXCEPT one (the modeled fault's channel) → observability/controllability improved over strict dedicated scheme.
- 11.2 State estimation / Kalman filter: discrete-time MIMO process; pole-placed Luenberger converges fast with large H but is NOT optimal under stochastic disturbances — reconstruction must track state AND reject noise → becomes an estimation problem.
- KF setup: process + input noise v(k) (cov matrix from M) and output noise n(k) (cov N), both Gaussian, zero mean, statistically independent; x(0) unknown but probabilistic info known; A,B,C,V,M,N known. Minimize LS criterion E{(x−x̂)ᵀ(x−x̂)}.
- Estimation taxonomy: k > j = prediction, k = j = filtering, k < j = smoothing [11.23]; text pursues filtering + one-step-ahead prediction.
- Kalman filter (11.2, eqs 11.43-11.78): combine prediction x̂(k+1|k) from process model with new measurement y(k+1) via weighted mean; gain K(k+1) chosen to minimize estimation-error covariance P; minimum found by completing the square in K ([11.1],[11.14]) → standard prediction/correction recursion [formulas not decoded — standard KF forms reconstructed].
- K(k+1) depends only on A, C, noise covariances M (input noise v), N (output noise n) — not on measured signals → computable off-line; time-invariant process → K → steady-state K, P → steady-state P∞ from a discrete Riccati equation (duality to optimal state control).
- KF vs Luenberger observer: observer uses only past u(k), y(k); KF adds model prediction x̂(k+1|k) + fresh y(k+1). Observer equation equals KF if observer gain set as function of KF gain [H = KC, reconstructed]. Fig 11.4 signal-flow diagram.
- Alt derivations: orthogonality of estimation error to measurements [11.17]; conditional-expectation/least-squares projection of x(k) on measurement set. Refs [11.4],[11.10],[11.15],[11.2],[11.19],[11.28],[11.29].
- KF for FDI [11.22]: residual = innovation; under fault-free operation it is zero-mean white noise with known covariance; a fault changes that character → detect. Best suited for processes with relatively large state/output noise.
- 11.3 Output (functional) observers: if state faults irrelevant, reconstruct only outputs; goal = observer whose residual responds ONLY to faults f(t), not to measured input u(t) nor unknown input v(t) → input-decoupled residual generation; rich literature on unknown-input observers [11.27],[11.6],[11.5]; derivation follows [11.8],[11.13].
- Output observer design (11.3 cont.): linear transformation ξ = Tx builds observer in new coords; observer output ≠ y so no direct output error — residual is a transformed comparison (Fig 11.5); observer feedback structure = parallel process model (no output-error feedback like 11.1). Ag chosen diagonal with stable poles.
- Decoupling conditions (eqs 11.95-11.99, [formulas not decoded — words]): state error and residual must be independent of unknown state contributions, unknown disturbance v(t), and known input u(t) — a linear matrix-equation set; plus an extra condition from the internal (Laplace) fault-to-residual form. If satisfied and state error → 0, residual depends ONLY on faults f(t).
- Solving the decoupling set: Kronecker canonical form [11.9], eigenstructure assignment [11.5], iterative singular-value-decomposition procedure [11.18], or relatively simple solution of [11.24]/[11.13].
- Cost: unknown disturbance-entry matrix V must be known PRECISELY (it sets transformation T); process model (A,B,C) must be accurate; lots of design freedom but at cost of effort and transparency.
- Residual internal form ≈ parity eq (10.8): faults filtered by a transfer function, but here independent of input disturbance v.
- 11.4 Comparison parity vs observers: same measured u,y; same assumptions (exact fixed model; V known if v compensated). Residual Laplace forms (output error 10.7, equation error 10.11, structured 10.52, state-space parity 10.29, state observer 11.14, output observer 11.101) are structurally VERY similar — differ only in how input/output measurements are filtered.
- Equivalence results: unknown-input observer ≡ parity-equation approach when observer designed deadbeat [11.9] (also [11.5]); Luenberger state observers ≡ parity equations [11.20],[11.11]; [11.13]: state observer vs reduced-order unknown-input observer vs state-space parity on DC motor → identical residual deflection for armature-resistance fault (theory + experiment).
- 11.4.2 DC-motor simulation study: simplified model from armature circuit eq (La dIa/dt = Ua − Ra Ia − Ψω [reconstructed]) + mechanical eq (J dω/dt = Ψ Ia − MF ω − ML [reconstructed]); variables: Ua armature voltage (input), Ia current, ω angular speed (output), ML load torque (disturbance), MF viscous friction, La inductance, Ra resistance, Ψ flux linkage; La « Ra allows further simplification; Ml(s)=0 assumed for parity generation.
- DC-motor residual comparison (Figs 11.7-11.9): expected deflections for additive faults; usable deflections for PARAMETRIC faults only for ΔRa, ΔΨ (no input excitation) plus ΔLa under step input excitation. If output is noisy, prefer output-error over equation-error residuals.
- Luenberger observer w/ two measured outputs (Ia, ω): model load torque ML as disturbance and decouple; poles λ1,2 = −500 1/s; decoupling forces residuals independent of mechanical subsystem → faults in MF, J undetectable; two equal residuals result. Output observer (same decoupling + poles): Cδ, T rows collapse → identical residuals, nearly same deflections.

### Ch12 Fault detection of control loops (src 6568-6854)
- Preamble: closed-loop goals (setpoint tracking, disturbance compensation, stabilization, parameter-change insensitivity); Fig 12.1 loop with reference w, control deviation e, manipulated variable u, process disturbances vj/uy, measurement noise ηs, faults of controller fc / actuator / process fp / sensor fs. Usually ONLY e and y are monitored.
- 12.1 Why closed loop hides faults (caution already raised in Ch2): small actuator/process faults (additive or multiplicative) are compensated by the feedback controller (integral action) → invisible in e(k), y(k) as long as e returns to ~0. Small sensor OFFSET faults undetectable: controller just makes the wrong sensor signal equal the reference; detection needs a redundant sensor or redundant information on the controlled variable.
- Table 12.1 (large faults) vs Table 12.2 (external disturbances, well-tuned loop) [both tables OCR-garbled, arrows indicate increase/decrease]: sluggish / oscillatory / large control error / actuator-at-restriction symptoms appear for nearly ALL fault types (process parameter change, friction, backlash, stuck, sensor offset/gain, controller parameters, wrong tuning) AND for plain disturbances → symptom patterns ambiguous, diagnosis from behavior alone not easy.
- Practical motivation: plants have hundreds of loops; [12.4]: up to 30% of loops oscillate in pulp & paper processes → put to manual or wrongly detuned; valve stiction often blamed (less so with position-controlled valves).
- 12.2 Signal-based performance monitoring: Harris-type index Jp = σy²/σ²_MV ≥ 1 [12.7] — compare actual control variance with minimum-variance controller benchmark; only process knowledge needed = dead time; variants [12.18],[12.17],[12.16] (control-structure constraints), oscillation/sluggishness detection [12.5], settling-time/time-delay index [12.19], modified Harris + MV controller with one pole off origin + valve-stiction diagnosis [12.8]. Limitation: assumes stochastic y; normal operating data not always stochastic — unsolved diagnosis cases [12.3].
- MV benchmark caveats: optimal for colored stochastic output disturbances (y becomes white noise); with dead time requires excessive manipulation effort and leaves offset for persistent/deterministic disturbances → use generalized MV (penalty r on u(k)) instead; MV a poor practical reference.
- [12.2] step-reference fault study (Fig 12.2): plant = 2nd-order actuator w/ small Coulomb friction + 2nd-order linear process + 1st-order sensor, optimized PID; six 10% faults: F1 sensor offset, F2 ↑process gain, F3 ↑actuator friction, F4 offset in manipulated variable, F5 ↑sensor time constant, F6 ↑sensor gain. Six criteria: overshoot, settling time, rms control deviation, rms manipulation, zero-crossing count, Δu(∞).
- Results (Table 12.3, signs of effects [table partly OCR-garbled]): F1, F5 show NO effect on y AND u (perfectly hidden!); F4 no y effect but drastic u reduction; F2/F6 gain faults → strong oscillations + lower steady-state u; ↑friction → oscillations at much lower frequency. Controller compensates all faults over time; u behavior distinguishes all faults except F5 → INCLUDE manipulated variable in performance evaluation. Six criteria → different pattern per fault → isolation possible with multi-criteria evaluation.
- Active test (step of w) usable when process conditions allow (natural in servo/position loops); continuous supervision for stochastic/pulse/drift disturbances needs developed methods. Se–Su plane [12.11],[12.12] (Fig 12.3): quadratic control deviation Se vs quadratic manipulation effort Su, different controllers (deadbeat DB, MV, state controller SC, pole assignment LCFA) occupy distinct areas for given processes; process parameter deviations push point out of tolerance zone around (Se0, Su0) (Fig 12.4); criteria |Se−Se0| ≤ ΔSe, |Su−Su0| ≤ ΔSu [reconstructed] + performance ratio ρ.
- Autocorrelation (ACF) of control deviation reveals excitation type (colored noise vs periodic signals) cheaply. Criteria averaged over sliding window length N or with exponential forgetting [formulas not decoded].
- 12.3 Oscillation detection: (1) IAE between successive zero crossings [12.5] — if few detections likely load disturbance; if many (threshold Nim ~ 10) likely true oscillation; threshold uses ωi ≈ 2π/Ti, Ti = PID integral time, amplitude e.g. 1%. (2) cross-correlation function (ccf) of u,y [12.9],[12.8]: oscillating external disturbance / unstable loop → phase shift ≈ π → EVEN ccf; static friction → phase shift ≈ π/2 → ODD ccf [as printed, 2/2 an OCR of π/2]. (3) Fourier analysis: peak at base ω plus odd harmonics 3ω, 5ω for nonlinearity-driven oscillations (friction, backlash) vs pure sinusoid; compute only distinct frequencies (Fig 12.5).
- 12.4 Model-based: track process + disturbance model changes = MIAS/self-tuning machinery [12.15],[12.1]; closed-loop ID conditions without test signals: model order & dead time exactly known; controller order ν ≥ m − d; enough natural excitation. Same disturbance-vs-parameter-change ambiguity plagues adaptive-system supervision [12.14],[12.15],[12.6].
- Parity equations in closed loop (Fig 12.6): output-error residual generally depends on reference w AND model mismatch; if Gp = Gm the w term cancels and residual = f(disturbance, additive input/output faults) EXACTLY as in open loop (cf 10.4/10.6). Same for polynomial/equation error when Ap=Am, Bp=Bm. → transfer-function parity method transfers unchanged to linear closed loops; detects e.g. sensor offsets, Coulomb friction, backlash (last two give direction-dependent residuals fa = sign(·) or ∝ sign u [12.13]).
- Caveats: large disturbances n → widen residual thresholds → only large faults detectable; residuals stay silent when loop oscillates from wrong tuning / instability as long as model is accurate (that's the flip side of closed-loop hiding). Conversely residual reconstructs disturbance n̂ when model agrees and no faults → classify disturbance type (stochastic/deterministic/drift/periodic).

### Ch13 — Fault detection with Principal Component Analysis (PCA) (lines 6855-7142)
- Chapter intro: multivariate statistics esp. PCA and PLS (projection to latent structures) gain attention when process measurements are highly correlated but only a few events (faults) produce unusual patterns; PCA models basically linear/static, developed from process data in NORMAL operation ([13.9]-[13.11]).
- 13.1 Principal components: reduce dimensionality of m interrelated variables to r < m uncorrelated components retaining most of the data variance; new coordinates = orthogonal directions of maximal data variation, first few components capture the variance.
- Data matrix X (m variables x_i(k), N samples) -> transformed T = P^T X, P orthonormal rotation (P^-1 = P^T); T = score matrix, P = loading matrix (multivariable-stats terminology).
- Stepwise optimization: each component t_j = p_j^T x maximizes variance s_jj under constraints p_j^T p_i = delta_ij (orthonormality); Lagrange multipliers with g = p_j^T p_j - 1 = 0 -> classical EIGENVALUE problem A p_j = lambda_j p_j, A proportional to covariance/correlation matrix of zero-mean variables; max variance of t_j = lambda_j -> largest eigenvalues = most significant directions [reconstructed standard PCA forms; source formulas not decoded].
- Procedure (6 steps as listed): 1) correlation matrix with E{x_i}=0, E{x_i^2}=1; 2) eigenvalues lambda_i + eigenvectors p_i; 3) keep r largest lambda; 4) P from selected eigenvectors; 5) T = P^T X, t_j = X^T p_j -> data matrix with all N samples but r < m coordinates, ~same variance info as X; 6) BACK-TRANSFORMATION X* = P P^T X restores original coordinates with only significant variances -> insignificant NOISE effects removed (PCA as noise filter).
- Dynamic PCA: expand data vector with delayed samples x*(k) = [x(k), x(k-1), ...] (discrete) or derivatives [x, dx/dt] (continuous) -> PCA applicable to dynamic processes.
- Example 13.1 (first-order process + white output noise, sinusoidal excitation): data in [y, dy/dt, u] fluctuate around a plane in 3D; eigenvalues of X^T X (Table 13.1 garbled [OCR?]: two large ~5847, one small ~491-637) -> smallest lambda negligible, keep 2 components; back-transformed data concentrate in one plane = visible noise reduction.
- 13.2 Fault detection with PCA — three schemes (Fig. 13.7):
  - (a) change detection (Ch7 statistics: mean, variance) applied DIRECTLY to scores t_j; problem: interpretation hard, and new variance in directions PCA NEGLECTED stays undetected [13.7].
  - (b) change detection on back-transformed X* = P P^T X; deviations link directly to process variables x_i(k).
  - (c) RESIDUAL route: r = X - X* (= P P^T X), monitor mean/variance of r; captures difference between present data and their PCA-model image; threshold exceeded -> fault. This is how residuals "embed" in PCA: residual = distance from the normal-operation subspace.
- Example 13.2 (real-time): learning phase 10 s -> compute P once; then per sample (Ty = 0.02 s) back-transform, residual vector r(k), squared residual quantity r^T r; detects time-constant change T 5s->3s, gain change K 1->2, output offset — y*(k) (denoised, model-consistent) does NOT contain the fault effect so r grows. KEY LIMIT stated verbatim: "based on this quantity the changes cannot be isolated" -> scalar residual energy detects but gives NO isolation.
- Literature pointers: [13.12], [13.8], [13.2]; application example = automotive wheel suspension, Ch22.
