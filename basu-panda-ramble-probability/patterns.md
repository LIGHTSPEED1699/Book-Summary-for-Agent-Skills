# Cross-chapter patterns (A Ramble through Probability)

1. **Approximate the hard by the easy, then pass to limits.** Simple functions ↑ measurable functions; cylinders → product σ-algebras; step functions → integrals; dyadic intervals → coin sequences. The limit step is always licensed by MCT/Fatou/DCT or by a σ-algebra closure argument — never hand-waved.
2. **The inheritance / good-sets engine.** To prove "all product-measurable (or generated) sets have property P": show the class of P-sets is a monotone class/λ-system containing the generating π-system. Ch4's good sets and the Monotone Class Theorem (10.3.3 ★) are the same move; use it whenever a claim is "obvious on rectangles".
3. **Countability buys uniformity.** Right-continuity + Q-countable dense set turns a.s. statements per-rational into one null set for all reals (regular conditional distributions 12.6, Helly's diagonal argument, Glivenko-Cantelli grids, SLLN subsequences ⌊α^j⌋). If you need "simultaneously for all x", discretize on a countable dense set and control the modulus.
4. **Cancellation is orthogonality is independence.** ∫RᵢRⱼ=0 (Ch3) → E[XY]=E[X]E[Y] (Ch6-7) → φ_{X+Y}=φ_Xφ_Y (Ch15) → the CLT's exponential limit. Fourth-moment counting (m + 3m(m−1) surviving terms) is the same combinatorics.
5. **Borel-Cantelli is the default 0-1 tool.** Summable failure probabilities ⇒ eventual success a.s. (BC1, used in SLLN subsequences, Glivenko-Cantelli, random series); independent + divergent ⇒ recurrence a.s. (BC2, unfair coins, typewriter). Tail triviality (0-1 law) caps what asymptotic questions can ask.
6. **Domination = tightness = no dominating summand.** DCT's envelope g, Prokhorov's tight intervals, Lindeberg's condition, and Lévy's "continuous at 0" are one idea in four costumes: **rule out mass escaping or concentrating**. When a limit theorem fails, look for escaped/concentrated mass (Cauchy spikes, uniform on (−j,j)).
7. **RN derivative is a universal solvent.** Conditional expectation = dν/dµ on a sub-σ-algebra; densities = dP/dµ_L; Bayes = disintegration backwards; Riesz representation (✖) = dφ on Lp duals. Any "derivative of measures" question is one theorem.
8. **Projection viewpoint for estimation.** E(X|Y) minimizes MSE over functions of Y (12.5.8); L² is Hilbert (9.7); orthogonal = uncorrelated. Optimal predictors, filters, and regression are instances; uncorrelated ≠ independent unless Gaussian.
9. **Characteristic functions: Taylor + continuity at 0.** Every limit law in Ch14-16: standardize → expand log φ to the first surviving order → recognize the target φ → invoke Lévy continuity. Failure analysis = the expansion breaks (infinite variance) or the limit is discontinuous at 0 (mass escape).
10. **Bias-variance is an approximate-identity tradeoff.** KDE: bias ~ δₘ²f″, variance ~ 1/(mδₘ); Bochner's theorem licenses δₘ→0. Same skeleton as any smoothing/regularization schedule.
11. **Counterexamples are maintained infrastructure.** The book keeps a gallery (typewriter sequence, unfair coins, escaping χ_{[i,∞)}, Cantor, Cauchy sums, AR(2) sums, non-converging densities with weak convergence) precisely at each theorem's boundary. When generalizing a result, check the gallery for which hypothesis you dropped.
12. **Worked problems as the verification loop.** Every chapter ends with worked problems; ★ marks the spine, ✖ the optional branches. The self-study protocol: read a section, do the problems, only then proceed — the book's difficulty ladder is intentional (Ch2 "admittedly very dry... very important").
