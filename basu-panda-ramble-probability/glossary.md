# Glossary — A Ramble through Probability (Basu & Panda)

- **Experiment / sample space / trial** — repeatable procedure, its set of possible single results, one performance (Ch1).
- **Bernoulli sequence** — infinite sequence of independent two-outcome trials (Def 3.1.1); space B ↔ [0,1] via binary expansion.
- **Rademacher functions** Rᵢ — ±1 step functions on dyadic intervals; the i-th coin as a function on [0,1]; orthogonal: ∫RᵢRⱼ = 0.
- **Normal numbers** — sequences with asymptotic frequency 1/2; measure zero complement; probability 0 ≠ impossible.
- **Algebra / σ-algebra** — sets closed under complements + finite / countable unions; **σ(E)** = minimal σ-algebra containing E; maximal = power set.
- **Measure** — countably additive µ: σ-algebra → [0,∞], µ(∅)=0; **σ-finite**; continuity from below/above (above needs a finite member).
- **Jordan measure** — inner/outer content by elementary sets; fails for Q∩[0,1]; the historical dead end motivating Lebesgue.
- **Outer measure µ\*** — subadditive size on ALL subsets, built by infimum over covers.
- **Carathéodory condition** — A measurable iff µ*(E) = µ*(E∩A)+µ*(E∩Aᶜ) for all test sets E; measurable sets form a σ-algebra.
- **Premeasure** — countably additive µ₀ on an algebra; **Carathéodory extension** extends it to σ(algebra), unique if σ-finite.
- **Completion** — adjoin all subsets of null sets; Lebesgue measure is the completion of Borel measure.
- **Lebesgue measure µ_L** — extension of length from half-open intervals; translation invariant.
- **Lebesgue-Stieltjes measure µ_F** — measure from increasing right-continuous F with µ_F((a,b]) = F(b)−F(a); distribution functions ↔ probability measures on ℝ.
- **Singular measures / Cantor function** — continuous increasing, derivative 0 a.e., carries a singular measure.
- **Probability space (Ω,F,P)** — Kolmogorov model; events = measurable sets.
- **{Aᵢ i.o.} = limsup Aᵢ** = ∩ₙ∪_{i≥n}Aᵢ — "infinitely often".
- **Borel-Cantelli 1 / 2** — ΣP(Aᵢ)<∞ ⇒ P(i.o.)=0; independence + ΣP(Aᵢ)=∞ ⇒ P(i.o.)=1.
- **Tail σ-algebra** — ∩ₙσ(Aₙ,Aₙ₊₁,…); events blind to finite prefixes; Kolmogorov 0-1 law: tail events of independent sequences have probability 0 or 1.
- **Measurable function** — preimages of Borel sets are measurable; σ(Y) = information carried by Y; simple-function approximation.
- **Pushforward / induced measure** — ν(B)=µ(f⁻¹(B)); for r.v.: distribution P_X, distribution function F_X (monotone, right-continuous, limits 0/1).
- **Lebesgue integral** — simple → nonnegative (sup) → difference; expectation E(X)=∫X dP.
- **MCT / Fatou / DCT / BCT** — the monotone, liminf, dominated, bounded convergence theorems (Ch8 ★).
- **Riemann-Stieltjes / Lebesgue-Stieltjes integral** — ∫g dF both ways; equal for distribution F and nice g (Thm 8.4.1).
- **MGF** M(s)=E e^{sX} — may fail to exist; moments by differentiation where finite.
- **Lp space** — ‖X‖_p=(E|X|ᵖ)^{1/p}, a.e.-identified; complete (Riesz-Fischer); L² Hilbert with ⟨X,Y⟩=EXY.
- **Product σ-algebra ⊗Fᵢ** — generated by rectangles (finite products) or cylinders (countable products).
- **Monotone Class Theorem** — promote "true on a π-system" to "true on generated σ-algebra" (10.3.3 ★).
- **Fubini / Tonelli** — swap iterated integrals: integrable / nonnegative hypotheses respectively.
- **Cylinder set** — finitely-constrained coordinates; generalized rectangles are the wrong generators in infinite dimensions.
- **Kolmogorov Consistency Theorem** — consistent finite-dimensional distributions ⇒ unique process measure on the product (10.11.2 ★).
- **Signed measure / countably additive set function** — φ: M → R, not both infinities; absolute convergence of disjoint series.
- **Hahn decomposition** — domain split A⁺/A⁻ where φ is nonnegative/negative; **Jordan decomposition** φ=φ⁺−φ⁻; total variation |φ|.
- **≪ / ⊥** — absolute continuity / mutual singularity; **Lebesgue-Radon-Nikodym**: φ_ac = f dµ, f = dφ/dµ unique a.e. (11.3.1 ★).
- **Conditional expectation E(X|G)** — the G-measurable r.v. matching integrals over G; a.s. unique; = RN derivative; = L² projection (best approximation by functions of Y).
- **Tower law** — E(E(X|G)|H) = E(X|H) for H ⊂ G; **taking out what's known**.
- **Regular conditional probability / distribution** — kernel Φ(ω,B) that is a true measure in B and equals P(X∈B|G)(ω) a.s. (12.6.1 ★).
- **Disintegration** — {Φ_y} concentrated on fibers Y⁻¹(y); P(A)=∫Φ_y(A)dP_Y(y) (12.7.1 ★); density form = Bayes machinery.
- **Convergence: a.s. / in probability / in Lp / in distribution** — the ladder; a.s. ⇒ probability ⇒ (subsequence a.s.); distribution sees only laws.
- **Empirical distribution Fₘ; Glivenko-Cantelli** — uniform a.s. convergence of Fₘ to F (13.3.3 ★), "fundamental theorem of statistics".
- **Weak convergence** — Fᵢ→F at continuity points; Portmanteau equivalences; **tightness** (no escaping mass); **Helly selection** + diagonal argument; **Prokhorov** (tight ⇒ relatively compact); **Scheffé** (a.e. densities ⇒ L¹).
- **Slutsky** — combine ᵈ→ with ᵖ→ constants (sums, products, quotients).
- **Characteristic function φ_X(t)=E e^{itX}** — Fourier-Stieltjes transform of the law; always exists; independence ⇒ product; Lévy **inversion** and **uniqueness**; moments ↔ differentiability; **Lévy continuity theorem** (pointwise limit continuous at 0 ⇒ weak convergence).
- **Lindeberg condition / u.a.n.** — no summand's large-deviation variance share survives; uniform asymptotic negligibility; **Lindeberg-Feller CLT** (sufficiency + necessity); **triangular arrays**.
- **Delta method** — push CLTs through differentiable maps (16.5.2 ★), from a perturbation theorem.
- **Kernel density estimate** — fₘ = (1/mδₘ)Σω((x−Xᵢ)/δₘ); naive estimate; bandwidth δₘ; rectangular/triangular/**Gaussian** kernels; **Bochner** approximate-identity theorem; bias ~ δₘ²·curvature, variance ~ 1/(mδₘ).
