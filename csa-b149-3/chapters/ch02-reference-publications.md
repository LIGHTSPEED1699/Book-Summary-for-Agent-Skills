# Chapter 2 — Reference Publications (Clause 2)

## Overview
Clause 2 lists the standards that components, systems, and installations referenced throughout B149.3 must be certified or designed to. A field approval is only as strong as the certification of its parts; this clause is the lookup table for those certifications.

## Core Content
Key referenced standards and their roles:

| Standard | Governs |

| CSA/ANSI Z21.21/CSA 6.5 | Automatic gas safety shut-off valves (the primary SSOV standard) |
| CGA 3.9 | Factory-installed/internal-configuration gas safety shut-off valves |

## How to Use This Table
1. When a component arrives on site, find its certification mark(s) and match them to this clause's list.
2. If a component lacks the required certification, Clause 10's field-approval documentation path is the alternative (engineering evaluation by the AHJ).
3. "C/I" marking on a Z21.21/6.5 valve indicates close-and-interlock (manual reset) — this substitutes for a second SSOV in many trains.

## Key Takeaways
- Nearly every component requirement in B149.3 traces back to a certification standard in Clause 2 — check here before specifying substitutes.
- SSOV certification: Z21.21/CSA 6.5 for most; CGA 3.9 for internal/factory-style configurations; combination controls Z21.78/6.20 only at low input.
- The Code is a companion to B149.1 (installation), B149.2 (propane handling), B149.5 (field approval sibling), and B149.6 (portable).
- Annex-specific standards (ISO 23552-1, ISO 16852, CGA G-4.1, IEC 61511) are mandatory-adjacent when those annexes are adopted.
